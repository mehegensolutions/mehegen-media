# mehegen-media

Finished media for MeheGen Solutions social posts (Instagram, Facebook, YouTube), scheduled through Metricool.

## Structure
```
YYYY/MM/YYYY-MM-DD_post-name/
    slide-01.jpg …           carousel slides (1080x1350, 4:5)
    vertical-9x16.mp4        Reels / Shorts (1080x1920)
    horizontal-16x9.mp4      YouTube long-form / LinkedIn / website
    youtube-short-9x16.mp4   carousel turned into a Short
```
The folder date is the publish date. Only finished, public-ready files go here: never client files or drafts.
